## 📖 What Each Prompt Does

### **0️⃣ MACRO TRENDS ANALYZER**
```
Input:  India's economic mood, sector analysis request
Output: Identified tailwind sectors (5-10 year winners)
        Identified headwind sectors (avoid these)
        Sector momentum ranking (top opportunities)
        Red flags (when to go defensive)
Time:   15-20 minutes
```

### **1️⃣ QUALITY SCORE ASSESSMENT**
```
Input:  Company financial data (5 years)
Output: Quality score (0-10)
        Profitability, cash flow, management, growth ratings
        Investment decision framework
Time:   30-45 minutes
```

### **2️⃣ COMPETITIVE MOAT ANALYSIS**
```
Input:  Company business model & competitors
Output: Moat type identified (brand/switching/scale/etc.)
        Moat strength rating (0-5 stars)
        Durability (how long will it last?)
Time:   20-30 minutes
```

### **3️⃣ DCF VALUATION (Intrinsic Value)**
```
Input:  Free cash flow data, growth assumptions, WACC
Output: Intrinsic value range (Bear/Base/Bull cases)
        Margin of safety calculation
        Sensitivity analysis table
Time:   25-35 minutes
```

### **4️⃣ RISK ASSESSMENT**
```
Input:  Company risks & threats
Output: Risk matrix (impact vs probability)
        Deal-breaker analysis
        Red flags to watch
Time:   20-30 minutes
```

### **5️⃣ HTML REPORT GENERATOR**
```
Input:  All above analysis
Output: Beautiful HTML report
        Dark mode theme (eye-friendly)
        Color-coded status (green/amber/red)
        ASCII charts (token-efficient!)
Time:   15-20 minutes
```
